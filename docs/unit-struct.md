# Unit struct: numeric fields

Generated by `python tools/dump_stats.py <rom> --md`.

`sub_080C7EA4(unit, statId)` dispatches through a 69-entry jump table where
each case loads exactly one field, so this mapping is read off the code rather
than inferred. 65 of 69 ids resolve to a direct load; the remaining four take
the address of a field instead (`0x00`, `0x09`, `0x1C`, and one more), which
means they return pointers to sub-structures.
